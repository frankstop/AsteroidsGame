# AsteroidsGame

A browser-based arcade game inspired by the classic **Asteroids** experience.

Built with **HTML5 Canvas**, **CSS**, and **vanilla JavaScript**, this game runs directly in the browser and is suitable for deployment with **GitHub Pages**.

## Live Demo

https://frankstop.github.io/AsteroidsGame/

## Preview

AsteroidsGame features a player-controlled spaceship, moving asteroids, bullets, screen wrapping, scoring, lives, hyperspace, and enemy saucers.

The game uses a fullscreen canvas with simple white vector-style graphics on a black background.

## Features

- Classic Asteroids-style gameplay
- Fullscreen canvas rendering
- Player-controlled spaceship
- Screen wrapping movement
- Asteroids that split into smaller pieces
- Bullet firing with a maximum bullet limit
- Score and lives display
- Extra life every 10,000 points
- Hyperspace jump
- Large and small enemy saucers
- Increasing levels
- No external libraries
- No build step required
- GitHub Pages compatible

## Controls

| Key | Action |
|---|---|
| Arrow Left | Rotate left |
| Arrow Right | Rotate right |
| Arrow Up | Thrust forward |
| Spacebar | Fire bullet |
| H | Hyperspace jump |
